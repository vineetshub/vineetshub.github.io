November 11, 2026 · Mentoring

Explaining a solution is part of solving it

Tutoring and programming both involve breaking a big problem into smaller steps. An answer can be correct and still leave someone confused if the explanation jumps over the part they don’t understand. That matters to me because I want the people I work with to be able to use an idea, not just accept it.

For a practice question, that might mean explaining why a tempting answer is wrong. In a software project, it might mean describing what a feature does before listing the tools behind it. In both cases, I think a useful next question is: could someone explain the idea back in their own words?

A question to think about

What makes an explanation click for you: an example, a diagram, or talking it through?

November 11, 2026 · Technology

A chart needs a little honesty

My finance-related projects make me think about the gap between displaying information and communicating it. A chart can look convincing even when it uses sample data or leaves out an important assumption. If a visitor cannot tell what the data represents, the design has missed something.

That’s why this portfolio identifies prototypes and describes what each project actually demonstrates. The financial charts dashboard uses fixed sample data, while the insider trading tracker distinguishes sample and API sources. I want a viewer to understand those differences before interpreting a result.

A question to think about

When you see a dashboard, what would help you decide whether to trust it?

November 11, 2026 · Reflection

Making a portfolio useful to someone else

It’s easy to build a portfolio around what I remember about a project. A visitor doesn’t have that context. A title and a cover image may look good, but they don’t explain the problem, the intended user, or the choices behind the work.

Revising this site helped me focus on those questions. I added a clearer introduction, explanations for the projects, and more ways to explore the work. The goal is for someone outside computer science to understand why a project matters, while still giving a technical reader a route to the source.

A question to think about

Which project would you like to hear more about, and what would you want to know?

Links worth keeping.

Resources for learning, preparing for opportunities, and helping students. Each link includes a reason to explore it.

Computer science

MDN Web Docs

A useful starting point for understanding HTML, CSS, and JavaScript. The explanations and small examples make it easier to connect something on a webpage to the code that creates it.

Computer science

Python documentation

The official tutorial is helpful when I want to check how the language works. It gives readers a foundation for understanding the Python tools used in several of my projects.

Career development

Rutgers Career Exploration and Success

A Rutgers-specific place to begin looking for career support and employer events. It connects the projects on this portfolio to the next step: explaining that experience to employers.

Career development

GitHub Skills

Interactive exercises for learning GitHub workflows. This is a useful companion to a portfolio because sharing code also involves documenting it and collaborating with other people.

Tutoring and learning

Khan Academy Digital SAT

Free SAT practice and explanations. I value having an accessible starting point students can use alongside a discussion of the questions they find difficult.

Tutoring and learning

College Board SAT Suite

The official source for SAT information and preparation resources. It is a good place to check the format and expectations before choosing additional study material.
